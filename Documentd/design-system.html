La app entera se apoya en app/styles/tokens.css. Ninguna pantalla escribe un color literal: si cambia un token, cambia todo. Esta página documenta la paleta, la escala tipográfica, los componentes y el orden normativo de cada vista.

Regla de oro: este sistema hereda la skill fabrick-design. Si el usuario pide “otro panel”, no se inventa una paleta nueva: se reutilizan estos tokens y componentes.

El orden de una pantalla

Norma heredada de fabrick-design. Toda vista nueva respeta esta secuencia:

  1. Header. Marca + acción de contexto (buscar, carrito, volver). Nunca duplicar navegación.
  2. Título y propósito. Una línea que diga qué hace la pantalla, sin adornos.
  3. Contenido primario. Lo que el usuario vino a ver o hacer, arriba y sin scroll.
  4. Contenido secundario. Relacionados, recomendaciones, ayuda.
  5. Acción. CTA fijo si la tarea es continua; inline si es una sección.
  6. Navegación inferior. Solo en destinos de tab. En flujos de compra se oculta el estado activo, no la barra.
  7. Notas y confianza. Pagos, garantía, persistencia local.

Respeta prefers-reduced-motion. Con movimiento reducido, todo aparece sin transición y sin parallax. El contenido nunca depende de una animación para ser visible.

Accesibilidad mínima

  • Contraste ≥ 4.5:1 en texto normal y ≥ 3:1 en texto grande.
  • Área táctil ≥ 44 × 44 px en acciones de icono.
  • Foco visible en todos los controles; nunca outline: none sin reemplazo.
  • Un h1 por vista; jerarquía sin saltos.
  • Botones con texto o aria-label; iconos decorativos con aria-hidden.
  • Formularios con label visible y errores en texto.

Qué no hacer

Evitar

  • Más de un CTA lima por pantalla.
  • Tarjetas con sombras grandes y bordes brillantes a la vez.
  • Texto gris claro sobre negro para párrafos largos.
  • Animaciones que bloquean el scroll o el primer render.
  • Fotos externas: el arte es SVG local.

Preferir

  • Jerarquía por tamaño y peso, no por colores nuevos.
  • Bordes finos y degradados suaves para el relieve.
  • Lima para acción, dorado para marca, gris para metadata.
  • Componentes compartidos antes que CSS nuevo.
  • Estados vacíos con una acción clara.
