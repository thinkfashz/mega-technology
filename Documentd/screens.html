Flujo crítico, paso a paso

  1. Descubrir. Home → categoría o producto. El arte SVG evita esperas de red.
  2. Elegir. Producto → color → cantidad. El stock se refleja en el CTA.
  3. Guardar. Carrito persistido; el badge del header se actualiza solo.
  4. Datos. Checkout valida y reutiliza el perfil en la próxima compra.
  5. Pagar. Se elige método; no hay cobro real en el prototipo.
  6. Enviar. Se elige entrega y se crea la orden MT-####.
  7. Seguir. La orden aparece en Mis pedidos con timeline.
  8. Operar. El panel cambia el estado; el cliente lo ve al instante.

Convención de carpetas

app/src/screens/<pantalla>/
├── <pantalla>.js    # render(ctx) + mount(root, ctx) + unmount()
├── <pantalla>.css   # solo estilos de esta pantalla
└── <pantalla>.md    # doc funcional (esta tabla)

app/src/ui/          # componentes compartidos (cards, chrome, arte, motion)
app/src/core/        # store, api, router, format, dom
app/styles/          # tokens, base, components

Regla: si un estilo se repite en dos pantallas, sube a components.css. Si un bloque se repite, sube a app/src/ui/.
