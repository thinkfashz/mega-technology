Scaffolding completo en Kotlin + Jetpack Compose + Material 3. Mismos tokens, mismo contrato de API, mismo orden de pantallas. Está en android/, listo para abrir en Android Studio y compilar.

No compilado acá. En este entorno no hay Android SDK. El código está completo y ordenado; compilar requiere Android Studio Hedgehog+ o SDK 35 y JDK 17.

Conectar con la API

# 1. Levantar el mock
node api/mock/server.mjs

# 2. En app/build.gradle.kts
buildConfigField("String", "API_BASE_URL", "\"http://10.0.2.2:8788/api/\"")
#    10.0.2.2 = host visto desde el emulador

# 3. Compilar
cd android && ./gradlew :app:assembleDebug

Checklist de calidad

  1. Tokens primero. Ningún hex literal en un composable.
  2. Una fuente de verdad. La API se llama desde el repositorio, nunca desde la pantalla.
  3. Estado observable. Un StateFlow por vista de datos, sin estado mutable en composables.
  4. Accesibilidad. contentDescription en íconos, área táctil ≥ 48 dp, contraste AA.
  5. Sin crashes. Validar listas vacías, errores de red y stock cero.
  6. Deep links. mega://product/p1, mega://orders, mega://admin.

Qué falta para producción

  • Room como caché offline y WorkManager para sincronizar.
  • Hilt en lugar del ServiceLocator.
  • BiometricPrompt real para la preferencia de biometría.
  • FCM para el push del estado de pedidos.
  • Tests unitarios del ViewModel y de la validación de checkout.
  • Screenshot tests de Compose para regresión visual.
